# Estrutura-de-Repetição
Exercícios de estrutura de repetição propostos na matéria de Raciocínio Algorítmico na PUCPR. Os exercícios utilizam a linguagem de programação Python e foram desenvolvidos no editor de código-fonte VS Code. São compostos por exercícios de estrutura de repetição, utilizando for i in range, while e while True. Também utiliza interação com o usuário em alguns.
